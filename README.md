# 🌍 Explore India – Travel Destination Website

Explore India is a responsive travel destination website designed to showcase
beautiful and popular travel destinations across India.

This project was developed as a frontend web development project using
HTML, CSS and JavaScript, with a focus on responsive design, modern UI and
interactive user experiences.

## 🔗 Live Demo
👉 https://esha3706.github.io/Explore-India-Travel-Website/
## 📌 Project Overview
-----------------------------------------
*** Explore India provides users with a simple and visually appealing way to
discover different travel destinations in India.

*** The website includes destination cards, a search feature, image gallery,
responsive navigation, dark mode and a contact form with basic validation.

## ✨ Features

- 🏠 Attractive Hero Section
- 🌍 Popular Indian Travel Destinations
- 🔎 Destination Search and Filter
- 🌙 Dark / Light Mode
- 📱 Responsive Design for Mobile, Tablet and Desktop
- 🖼️ Travel Image Gallery
- 🧭 Responsive Navigation Menu
- 💬 Interactive Destination Buttons
- 📩 Contact Form with Basic Validation
- ⬆️ Back-to-Top Button
- ✨ Smooth Scrolling
- 🎨 Modern and Clean User Interface
